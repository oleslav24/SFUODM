# CHANGELOG

## [0.5] - 2025-04-22
- Заменён Vue.js на React.js 19.x в стеке технологий и тестировании.
- Заменён Autodesk Forge API на КОМПАС-3D API для BIM-интеграции.
- Заменён GitLab на GitHub SaaS для CI/CD и репозитория.
- Исключён ELK Stack, логирование реализовано через Grafana Loki.
- Уточнена микросервисная архитектура (модули Управление БПЛА, Фотограмметрия, Хранилище данных).
- Добавлена оркестрация через Kubernetes в продакшене.
